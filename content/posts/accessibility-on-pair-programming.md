I use my screen reader and refreshable Braille display to access all information on my computer. Accessing Code Wars website was frustrating, because it’s not fully accessible. My screen reader wasn’t able to access someone’s screen to read his or her codes.





Fortunately, I found a solution that I was able to access Live Share in Visual Studio Code and I was happy with it. Google Codeweb also works for me.





Pair programming is helpful, because we enjoy working together while trying to solve a problem. Getting some ideas from people can help me figure out how to fix a bug.





I hope Code Wars should fix accessibility issues for blind computer programmers, so that they can effectively improve their coding skills.
