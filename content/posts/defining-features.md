I usually created issues and opened them on my GitHub. For example, one of my issues was “Backend: As a user, I can see an equation and a result after typing a script.” Issues are considered as user stories. The acceptance criteria for this user story is to successfully print a result and equation in Python when I get it done. I can set to “done” on this issue and close it.
