I chose to focus on backend for my calculator application. I was amazed that Python is powerful enough to calculate using many functions; therefore, I don’t need to specifically set up many small functions. For example, import math has plenty of functions. When I type “math.cos(30), it gives the result.





Once I complete the backend part, I will plan to start with the frontend part and build a simple webpage with a lot of buttons.





 I spent 40 hours per week working on backend, because I wanted to make sure that the calculations are correct as well as I imported math libraries in Python.





Backend allows me to debug and fix errors easily rather going back and forth between backend and frontend.





I plan to use Flask and Vue.js to build a webpage for frontend. I plan to spend a little less than 40 hours per week to complete the part on time.





Creating issues on GitHub helps me prepare and complete tasks, because my calculator application has many options.





I plan to complete the backend part by March 13 and the frontend part by May 1.





I definitely am using a lot of effort working on my umbrella project and plan to complete it on time. It’s very challenging, but it’s a lot of fun.
