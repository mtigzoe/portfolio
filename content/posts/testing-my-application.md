When I started to build a simple calculator app with a few features, I was able to test it without using automation. Once I added many more features to it, it was difficult to test all the features on my own. Using pytest benefits my app, because it  finds small bugs. Fixtures with random numbers are useful to some specific modes, such as real numbers or statistics. I don’t think that random numbers are helpful to test derivatives and integrals, so I have to choose a specific derivative.


Not testing my calculator app has resulted in a big fatal crash or can cause a large problem. Time, costs and features should be considered.


When I tried patchmonkey using pytest on my calculator application, it didn’t work, because the functions with user selections didn’t have any return value. It’s best for me to test my app on my own.


I think automated tests can help reduce bugs and are important for my app; however, it’s a good idea to take my time to test my app without using automation.
